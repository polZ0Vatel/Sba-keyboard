# Milky Nice Keyboard — сборка через GitHub Actions (Windows)

Этот репозиторий содержит исходный проект iOS-клавиатуры с приложенным шрифтом **Milky Nice**. На Windows можно загрузить проект на GitHub и запустить облачную сборку на macOS.

## Что уже включено
- Раскладки букв RU и EN.
- Шрифт Milky Nice на буквенных клавишах.
- Shift, Backspace, пробел, точка и Enter.
- GitHub Actions workflow для автоматической сборки.

## Как запустить сборку с Windows
1. Распакуйте архив.
2. Войдите на GitHub и создайте новый пустой репозиторий, например `MilkyNiceKeyboard`.
3. На странице репозитория нажмите **Add file → Upload files** и загрузите все файлы и папки из этой папки. Важно загрузить папку `.github` тоже. Если GitHub не показывает её, включите отображение скрытых файлов в Проводнике Windows.
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions** репозитория. Если GitHub попросит разрешить Actions, подтвердите.
6. Выберите workflow **Build Milky Nice Keyboard**, нажмите **Run workflow** → **Run workflow**.
7. Дождитесь зелёной отметки. Откройте завершённый запуск и скачайте artifact `MilkyNiceKeyboard-unsigned-ipa`.

## Важное ограничение: IPA пока без подписи
GitHub Actions в этом проекте собирает **unsigned IPA**. Такой файл полезен как результат сборки, но iPhone не установит его напрямую: iOS требует подпись приложения действительным сертификатом и provisioning profile. Не добавляйте пароли Apple ID или сертификаты в открытый репозиторий.

Чтобы получить устанавливаемую сборку, нужно отдельно настроить подпись приложения. Для этого обычно нужен Apple Developer аккаунт, сертификат Apple Distribution/Apple Development и provisioning profile для приложения и клавиатурного расширения. Сборка без платного членства может быть возможна для личного тестирования через Xcode на зарегистрированном устройстве, но для этого сценария понадобится отдельная настройка подписи.

## Ограничения первой версии
Это отдельная сторонняя клавиатура, а не изменение встроенной клавиатуры Apple. Вводимый текст остаётся обычным; меняется только шрифт надписей на клавишах. Числовой/символьный слой, подсказки, автокоррекция, эмодзи и диктовка пока не реализованы. В защищённых полях iOS может переключать пользователя на системную клавиатуру.

## Структура
- `HostApp/` — приложение-контейнер с инструкцией.
- `KeyboardExtension/` — расширение клавиатуры и файл шрифта.
- `project.yml` — описание Xcode-проекта для XcodeGen.
- `.github/workflows/build.yml` — облачная сборка на GitHub Actions.
